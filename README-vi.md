# XrayR

Backend Xray do Vergelab duy trì. Lệnh và tên tệp nhị phân vẫn là `XrayR`.

Phiên bản hiện tại: **0.1**

- Mã nguồn: https://github.com/Vergelab/XrayR
- Tập lệnh cài đặt và bản phát hành: https://github.com/Vergelab/xrayr-release
- Ảnh container: `ghcr.io/vergelab/xrayr`
- Tài liệu đầy đủ: [README.md](README.md) (tiếng Trung), [README-en.md](README-en.md) (tiếng Anh)

## Cài đặt

```bash
wget -N https://raw.githubusercontent.com/Vergelab/xrayr-release/master/install.sh && bash install.sh
```
