# XrayR

بک‌اند Xray که Vergelab آن را نگهداری می‌کند. نام دستور و فایل اجرایی همچنان `XrayR` است.

نسخهٔ فعلی: **0.3**

- کد منبع: https://github.com/Vergelab/XrayR
- اسکریپت نصب و انتشارها: https://github.com/Vergelab/xrayr-release
- تصویر کانتینر: `ghcr.io/vergelab/xrayr`
- توضیح کامل: [README.md](README.md) (چینی)، [README-en.md](README-en.md) (انگلیسی)

## نصب

```bash
wget -N https://raw.githubusercontent.com/Vergelab/xrayr-release/master/install.sh && bash install.sh
```
